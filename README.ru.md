# XQuasar

XQuasar сам находит в домашней папке Linux кэш, который приложения могут создать заново, и подтверждённые остатки Flatpak. При запуске появляется план очистки. Неопознанные каталоги приложений и личные файлы сохраняются.

## Установка на Linux Mint, Ubuntu или Debian

[Скачать XQuasar (.deb)](https://github.com/glitchykid/xquasar/releases/latest/download/xquasar.deb) · [Опубликованные версии](https://github.com/glitchykid/xquasar/releases)

Откройте скачанный файл и нажмите **Установить**. Затем выберите **XQuasar** в меню приложений. Менеджер пакетов установит компоненты для графического окна. Подходит дистрибутив с Python 3.12 или новее.

В тёмном окне видны общий объём распознанного кэша и категории, в которых нашлись файлы. Кнопка **Все проверки (20)** открывает каталог, включая категории с нулевым результатом. **Показать пути** раскрывает список файлов. Нажмите **Очистить…**, чтобы проверить действия и подтвердить. Через **Открыть папку восстановления** можно найти сохранённые профили и ярлыки.

Из рабочей копии проекта установщик можно собрать командой

```sh
sh packaging/build-deb.sh 0.5.0 ./xquasar.deb
```

## Запуск CLI из исходников

Нужны Linux и Python 3.12 или новее. Для клонирования исходников нужен Git. Если установлен Flatpak, программа также найдёт каталоги удалённых Flatpak-приложений. Запускайте её от имени владельца домашней папки.

```sh
git clone https://github.com/glitchykid/xquasar.git
cd xquasar
python3 -m xquasar
```

Первая команда только показывает план. Чтобы применить его, выполните команду ниже и введите `yes`. Для отмены нажмите Enter.

```sh
python3 -m xquasar --clean
```

## Что можно очистить

- **Восстанавливаемый кэш** — XQuasar проверяет PNG-миниатюры в четырёх каталогах размеров внутри `$XDG_CACHE_HOME/thumbnails` и двоичные файлы шрифтового кэша в `$XDG_CACHE_HOME/fontconfig`. Имя и заголовок файла должны соответствовать формату. По умолчанию корневой каталог кэша — `~/.cache`.
- **Кэш приложений** — XQuasar распознаёт файлы дискового кэша и кэша кода Chromium и Electron внутри каталогов приложений в `.config`, `.local/share`, `.local/state` и `.cache`. Он сверяет имя и заголовок файла. Также проверяются старые миниатюры в `~/.thumbnails` и кэш Python в `~/.local/lib/python3.*/site-packages`, если рядом сохранился исходник. Если после очистки распознанных файлов папка кэша браузера или Python опустела, она тоже удаляется.
- **Профили Flatpak** — XQuasar сравнивает каталоги в `~/.var/app` со списком установленных приложений и повторяет проверку после подтверждения. Если список получить не удалось, профили пропускаются. Прочий кэш и папки неизвестных приложений сохраняются.
- **Ярлыки Flatpak** — Ярлыки из `.local/share/applications` и записи автозапуска из `.config/autostart` перемещаются в папку восстановления, если имя файла, метка Flatpak и команда запуска указывают на одно удалённое приложение. Перед переносом XQuasar ещё раз проверяет список установленных приложений.
- **Другие приложения** — укажите известный каталог удалённого приложения через `--leftover`. Путь считается от домашней папки и должен указывать на непосредственную подпапку `.config`, `.cache`, `.local/share` или `.local/state`. Параметр можно повторять. Пример команды — `python3 -m xquasar --clean --leftover .config/OldEditor`.
- **Firefox и рабочий стол** — XQuasar распознаёт HTTP-кэш Firefox, кэш запуска браузера, скриптов, адресов и запуска расширений. Отдельно проверяются записи о неудачных миниатюрах, реестр модулей GStreamer и списки шрифтов Matplotlib.
- **Инструменты разработки** — В стандартных каталогах кэша программа ищет wheel-файлы pip, архивы npm, Cargo и Composer, пакеты из HTTP-кэша NuGet и записи о сборке Go. После очистки архивов для следующей сборки может понадобиться интернет.

Папки приложений целиком перемещаются в `~/.xquasar-recovery/<запуск>/<исходный-путь>`. Профили и сохранения можно вернуть — закройте приложение и перенесите папку обратно, если исходный путь свободен. Место на диске освободится, когда вы сами удалите резервную копию.

## Разработка и помощь

```sh
docker build -t xquasar-dev .
docker run --rm --network=none xquasar-dev
```

Контейнер запускает тесты во временных домашних папках. При неполном сканировании прочитайте строки `Skipped`. Если упоминается Flatpak, выполните `flatpak list --app --columns=application:f` от того же пользователя и повторите попытку.
