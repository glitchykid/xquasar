# XQuasar

XQuasar находит кандидатов на очистку в домашней папке Linux. В каждой строке видны путь и действие. Вы сами выбираете, какие позиции очистить.

## Установка на Linux Mint, Ubuntu или Debian

[Скачать XQuasar (.deb)](https://github.com/glitchykid/xquasar/releases/latest/download/xquasar.deb)

Откройте скачанный файл и нажмите **Установить**. Затем выберите **XQuasar** в меню приложений. Менеджер пакетов установит компоненты для графического окна. Подходит дистрибутив с Python 3.12 или новее.

При запуске откроется список для просмотра. Отметьте нужные строки, нажмите **Очистить выбранное…** и проверьте, сколько позиций будет удалено и сколько перемещено для восстановления. После подтверждения кнопка **Открыть папку восстановления** покажет сохранённые профили, если они были перемещены.

## Запуск CLI из исходников

Нужны Linux и Python 3.12 или новее. Для клонирования исходников нужен Git. Если установлен Flatpak, программа также найдёт каталоги удалённых Flatpak-приложений. Запускайте её от имени владельца домашней папки.

```sh
git clone https://github.com/glitchykid/xquasar.git
cd xquasar
python3 -m xquasar
```

Первый запуск только показывает список. Для очистки выполните следующую команду, введите номера через пробел или `all`, затем подтвердите выбор словом `yes`. Чтобы отменить, нажмите Enter.

```sh
python3 -m xquasar --clean
```

## Что можно очистить

- **Миниатюры** — удаляет выбранные файлы кэша со стандартными именами из 32 шестнадцатеричных цифр и расширением PNG. Проверяет четыре каталога размеров в `$XDG_CACHE_HOME/thumbnails` (по умолчанию `~/.cache/thumbnails`).
- **Пустые папки** — удаляет выбранные папки, пока они пусты. Пропускает скрытые каталоги, рабочие деревья Git и отдельные точки монтирования. Сохраняет стандартные и настроенные пользовательские каталоги XDG. Родительская папка, опустевшая после очистки, может появиться при следующем запуске.
- **Остатки Flatpak** — сравнивает папки в `~/.var/app` со списком установленных приложений и повторяет проверку после подтверждения. При недоступности списка пропускает эти папки.
- **Другие приложения** — укажите известный каталог удалённого приложения через `--leftover`. Путь считается от домашней папки и должен указывать на непосредственную подпапку `.config`, `.cache`, `.local/share` или `.local/state`. Параметр можно повторять. Пример команды — `python3 -m xquasar --clean --leftover .config/OldEditor`.

Папки приложений целиком перемещаются в `~/.xquasar-recovery/<запуск>/<исходный-путь>`. Профили и сохранения можно вернуть — закройте приложение и перенесите папку обратно, если исходный путь свободен. Место на диске освободится, когда вы сами удалите резервную копию.

## Разработка и помощь

```sh
docker build -t xquasar-dev .
docker run --rm --network=none xquasar-dev
```

Контейнер запускает тесты во временных домашних папках. При неполном сканировании прочитайте строки `Skipped`. Если упоминается Flatpak, выполните `flatpak list --app --columns=application:f` от того же пользователя и повторите попытку.
