## English

XQuasar recognises profile directories for 23 applications, including Blender, OBS Studio, GIMP, Transmission and Neovim. For 24 more KDE applications it checks individual settings files such as `.config/kcalcrc` and `.config/spectaclerc`. A profile move requires evidence of removal, a check for another installation and a fresh activity check. Settings and profiles go to recovery intact.

The 38 categories include Qt QML bytecode, darktable thumbnails, Thunderbird HTTP and startup caches, Chromium graphics entries, and caches for Go, Gradle, Electron, pip, RubyGems, Cabal, Helm, Composer and NuGet. XQuasar also checks recognised cache formats inside installed Flatpak and Snap apps. Offline builds may need to download packages again. Go outputs and Gradle archives are checked by digest up to 64 MiB per file. This package upgrades earlier versions without migration. [Download installer (.deb)](https://github.com/glitchykid/xquasar/releases/download/v0.7.0/xquasar.deb)
