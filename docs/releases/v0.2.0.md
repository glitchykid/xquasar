## English

[Download XQuasar for Linux Mint, Ubuntu or Debian (.deb)](https://github.com/glitchykid/xquasar/releases/download/v0.2.0/xquasar.deb). Open the file, click **Install**, then launch **XQuasar** from the applications menu. The desktop preview lets you check items, confirm permanent deletions and recoverable moves, and open the recovery folder. The package requires system Python 3.12+ and installs GTK dependencies through your package manager. Existing CLI commands and saved profiles remain compatible.
