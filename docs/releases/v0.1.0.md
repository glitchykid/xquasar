## English

First release of the XQuasar Linux CLI. Extract the source archive and run `python3 -m xquasar` from its directory with Python 3.12 or newer. The preview lists empty folders, thumbnail cache files, Flatpak leftovers and app directories supplied with `--leftover`. Use `--clean` to select and confirm. Application data moves to `~/.xquasar-recovery/` for recovery. Automatic app detection covers Flatpak and requires a working inventory. This initial release requires no migration.

## Русский

Первый выпуск XQuasar для Linux. Распакуйте архив исходников и выполните в его каталоге `python3 -m xquasar` с Python 3.12 или новее. В списке появятся пустые папки, кэш миниатюр, остатки Flatpak и каталоги приложений, переданные через `--leftover`. Для выбора и подтверждения добавьте `--clean`. Данные приложений перемещаются в `~/.xquasar-recovery/` для восстановления. Автопоиск остатков поддерживает Flatpak и требует доступа к списку установленных приложений. Миграция для первого выпуска не требуется.
