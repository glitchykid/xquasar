## English

Open XQuasar from the applications menu to see a ready-made plan. Review the thumbnail and Fontconfig cache sizes and confirmed Flatpak profiles, then choose **Clean up…** to confirm. Personal folders are kept, including empty ones. Unavailable Flatpak inventory skips profile cleanup. Installing this package upgrades v0.2.0 in place and preserves existing recovery copies. [Download the .deb installer](https://github.com/glitchykid/xquasar/releases/download/v0.3.0/xquasar.deb)

## Русский

Запустите XQuasar из меню приложений. Он сам покажет объём кэша миниатюр и шрифтов и количество профилей удалённых приложений Flatpak. Нажмите **Очистить…**, чтобы подтвердить план. Личные папки сохраняются, в том числе пустые. При недоступном списке Flatpak профили пропускаются. Установщик обновляет v0.2.0 с сохранением прежних копий для восстановления. [Скачать установщик .deb](https://github.com/glitchykid/xquasar/releases/download/v0.3.0/xquasar.deb)
