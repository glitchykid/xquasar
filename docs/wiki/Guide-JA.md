# 自動整理とプロファイルの復元

1. アプリケーションメニューから **XQuasar** を開き、集計結果を待ちます。キャッシュにはファイル数とサイズ、Flatpak には退避できるプロファイル数が表示されます。空の個人用フォルダーも保持します。
2. **パスを表示** で候補を確認できます。**整理…** を押すと、削除するキャッシュと退避するプロファイルの件数が表示されます。確認して実行するか、キャンセルしてください。
3. 復元するには、整理後に **退避先を開く** を押します。対象のアプリを終了してフォルダーを元のパスに戻します。同じ場所に新しいプロファイルがあれば両方を残して内容を比較してください。退避したコピーを削除すると、その分の空き容量が増えます。

ソースディレクトリで `python3 -m xquasar` を実行すると候補を確認できます。`python3 -m xquasar --clean` を実行して `yes` と入力すると整理を開始します。`Skipped` は確認や処理をスキップした項目を示します。終了コードは成功またはキャンセルが 0、一部完了が 1、入力エラーまたはホームにアクセスできない場合が 2 です。
