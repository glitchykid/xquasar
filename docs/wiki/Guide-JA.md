# 自動整理とプロファイルの復元

1. メニューから **XQuasar** を開きます。キャッシュの種類別の集計に加え、退避できる Flatpak プロファイルとランチャーの件数が表示されます。個人のファイルや用途不明のフォルダーは対象外です。
2. **パスを表示** で候補を確認できます。**整理…** を押すと削除するキャッシュと退避する項目の件数が表示され、実行またはキャンセルを選べます。
3. 復元するには整理後に **退避先を開く** を押し、対象アプリを終了して保存されたランチャーやプロファイルを元の場所に戻します。同名の項目がすでにあれば、両方を保持して内容を確認してください。

**アプリのキャッシュ** — `.config`、`.local/share`、`.local/state`、`.cache` 内のアプリ用ディレクトリで、Chromium と Electron のディスクキャッシュやコードキャッシュをファイル名とヘッダーで識別します。`~/.thumbnails` の旧形式の保存先と、対応するソースがある `~/.local/lib/python3.*/site-packages` の Python バイトコードも対象です。これらのブラウザーまたは Python のキャッシュフォルダーが整理によって空になった場合は削除します。

**Flatpak のランチャー** — `.local/share/applications` のメニュー項目や `.config/autostart` の自動起動項目は、ファイル名、Flatpak の識別子、起動コマンドが同じ削除済みアプリを示す場合に退避します。移動の直前にインストール済みアプリを再確認します。

ソースディレクトリで `python3 -m xquasar` を実行すると候補を確認できます。`python3 -m xquasar --clean` を実行して `yes` と入力すると整理を開始します。`Skipped` は確認や処理をスキップした項目を示します。終了コードは成功またはキャンセルが 0、一部完了が 1、入力エラーまたはホームにアクセスできない場合が 2 です。
