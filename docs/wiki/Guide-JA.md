# アプリのプロファイルを整理・復元する

アプリケーションメニューから **XQuasar** を開きます。残ったプロファイルは **アプリのフォルダーを追加…** で指定し、対象にチェックを入れて **選択した項目を整理…** を押し、確定します。**退避先を開く** で保存先に移動できます。ターミナルから実行する手順は次のとおりです。

1. アプリを終了し、ソースディレクトリから `python3 -m xquasar --leftover .config/OldEditor` を実行します。例のパスは、削除済みアプリに属すると分かっているディレクトリに置き換えます。各パスに対する処理が表示されます。
2. 同じコマンドに `--clean` を追加します。目的のフォルダーの番号だけを入力し、`yes` で確定します。自動検出された Flatpak のデータも同じ方法で退避されます。
3. 最後に表示される退避先のパスを控えます。ファイルマネージャーで隠しファイルを表示し、退避先の中で元の相対パス（例：`.config/OldEditor`）を開きます。プロファイルの中身を確認できます。
4. 復元するときはアプリを終了し、フォルダーを元の親ディレクトリに戻します。新しいプロファイルが既に作成されている場合は両方を保存し、内容を比較してから統合します。容量を空けるには、不要になったことを確認して退避先のコピーを削除します。

サムネイルと空のディレクトリは完全に削除されます。`Skipped` は、その項目の処理または走査の一部を完了できなかったことを示します。終了コード 0 は完了または中止、1 は一部完了、2 は入力の誤りまたはホームにアクセスできない状態です。原因を解消してから再度プレビューしてください。
