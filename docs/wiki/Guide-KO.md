# 자동 정리 및 프로필 복구

1. 애플리케이션 메뉴에서 **XQuasar**를 열고 검사 결과를 기다리세요. 캐시는 파일 수와 크기로, Flatpak은 복구 폴더로 옮길 수 있는 프로필 수로 표시됩니다. 개인 폴더는 비어 있어도 보관합니다.
2. **경로 보기**에서 목록을 확인할 수 있습니다. **정리…**를 눌러 삭제할 캐시와 이동할 프로필 수를 확인한 뒤 진행하거나 취소하세요.
3. 프로필을 복원하려면 정리 후 **복구 폴더 열기**를 누르세요. 대상 앱을 종료하고 폴더를 원래 위치로 옮기세요. 그곳에 새 프로필이 있으면 두 복사본을 모두 보관하고 내용을 비교하세요. 복구용 사본을 지우면 디스크 공간이 확보됩니다.

소스 폴더에서 `python3 -m xquasar`로 계획을 확인하세요. `python3 -m xquasar --clean`을 실행하고 `yes`를 입력하면 정리를 시작합니다. `Skipped`는 검사나 작업을 건너뛴 항목을 알려 줍니다. 종료 코드는 성공 또는 취소 시 0, 일부 완료 시 1, 입력 오류 또는 홈에 접근할 수 없는 경우 2입니다.
