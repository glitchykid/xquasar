# 앱 프로필 정리 및 복구

애플리케이션 메뉴에서 **XQuasar**를 엽니다. **앱 폴더 추가…**로 삭제한 앱의 프로필을 추가하고 해당 항목에 체크한 뒤 **선택 항목 정리…**에서 확인하세요. **복구 폴더 열기**를 누르면 보관된 프로필을 찾을 수 있습니다. 터미널에서는 다음 절차를 따르세요.

1. 앱을 종료하고 소스 디렉터리에서 `python3 -m xquasar --leftover .config/OldEditor`를 실행합니다. 예시 경로는 이미 삭제한 앱의 디렉터리로 바꾸세요. 각 경로에 어떤 작업이 적용될지 확인할 수 있습니다.
2. 같은 명령에 `--clean`을 추가합니다. 원하는 앱 폴더의 번호만 입력한 뒤 `yes`로 확인하세요. 자동으로 찾은 Flatpak 폴더도 같은 방식으로 보관합니다.
3. 마지막에 출력되는 복구 디렉터리 경로를 복사하세요. 파일 관리자에서 숨김 파일을 표시하고, 복구 디렉터리 안에서 원래의 상대 경로(예: `.config/OldEditor`)를 열면 프로필 내용을 확인할 수 있습니다.
4. 복구하려면 앱을 종료하고 폴더를 원래의 상위 디렉터리로 되돌리세요. 앱이 새 프로필을 만들었다면 두 사본을 모두 보관하고 내용을 비교한 뒤 병합하세요. 디스크 공간이 필요하면 보관한 사본이 더 이상 필요 없는지 확인한 후 삭제합니다.

미리보기 이미지와 빈 폴더는 영구 삭제됩니다. `Skipped`는 해당 항목이나 검사 규칙을 처리하지 못했다는 뜻입니다. 종료 코드 0은 완료 또는 취소, 1은 일부 처리, 2는 잘못된 입력이나 홈 디렉터리 접근 실패를 뜻합니다. 표시된 문제를 해결한 다음 다시 미리보기를 실행하세요.
