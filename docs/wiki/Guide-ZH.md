# 自动清理与恢复应用配置

1. 从应用程序菜单打开 **XQuasar**，等待扫描结果。缓存按类型显示文件数量和大小，Flatpak 一栏显示可以移入恢复目录的配置数量。个人空文件夹会保留。
2. 点击**查看路径**可以查看清单。点击**清理…**，核对要删除的缓存文件数量和要移动的配置数量，然后确认或取消。
3. 如需恢复配置，请在清理后点击**打开恢复目录**。关闭相关应用，将配置文件夹移回原路径。如果原位置已有新配置，请保留两份并比较内容。删除恢复副本后才会释放相应的磁盘空间。

在源码目录中运行 `python3 -m xquasar` 可以预览。要执行计划，请运行 `python3 -m xquasar --clean` 并输入 `yes`。`Skipped` 提示表示某项检查或操作被跳过。退出码 0 表示成功或取消，1 表示部分完成，2 表示输入有误或无法访问主目录。
