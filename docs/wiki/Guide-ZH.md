# 清理和恢复应用配置

从应用程序菜单打开 **XQuasar**。点击**添加应用目录…**选择已卸载应用的配置目录，勾选对应条目，点击**清理所选项…**并确认。可通过**打开恢复目录**查看保存的配置。如需使用终端，请按以下步骤操作。

1. 关闭应用，在源码目录运行 `python3 -m xquasar --leftover .config/OldEditor`。将示例路径替换为你确认属于已卸载应用的目录。预览会列出每个路径的处理方式。
2. 给同一条命令加上 `--clean`。只输入目标应用目录的编号，然后输入 `yes` 确认。自动识别的 Flatpak 目录也会以相同方式保存。
3. 记下程序最后输出的恢复目录。在文件管理器中显示隐藏文件，在恢复目录下打开原来的相对路径，例如 `.config/OldEditor`，即可查看配置内容。
4. 恢复时先关闭应用，再把目录移回原来的上级目录。如果应用已经创建了新的配置，请保留两份，比较内容后再合并。要释放磁盘空间，请在确认不再需要恢复副本后将其删除。

缩略图和空目录会被永久删除。`Skipped` 表示某个项目或某项扫描规则未能完成。退出码 0 表示完成或取消，1 表示部分完成，2 表示输入无效或无法访问主目录。解决提示中的问题后可再次预览。
